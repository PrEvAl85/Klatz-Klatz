# Klatz-Klatz

Мультиплатформенное приложение для переключения раскладки клавиатуры.
Живёт в трее, переключает раскладку по глобальной горячей клавише или по клику
на иконку. Работает полностью офлайн: ни сети, ни телеметрии, ни автообновлений.

Работает на **Windows**, **Linux (X11)** и **macOS**.

## Возможности

- Переключение по глобальной горячей клавише (по умолчанию `Ctrl+Shift+Space`)
- Переключение по клику на иконку в трее
- Меню трея со списком раскладок; активная отмечена галочкой
- Свой порядок раскладок в цикле: перетаскиванием в окне настроек
- Автозапуск вместе с системой
- Окно настроек закрывается в трей, а не завершает приложение
- Настройки хранятся в JSON рядом с другими конфигами приложения

## Установка

Готовые сборки публикуются в разделе [Releases](https://github.com/klatz-klatz/klatz-klatz/releases).

| Платформа | Файл | Замечание |
| --- | --- | --- |
| Windows | `Klatz-Klatz_*_setup.exe` или `.msi` | x64 |
| Linux | `.deb` или `.AppImage` | Требуется X11, см. ограничения |
| macOS | `.dmg` | При первом запуске macOS может запросить разрешение |

## Ограничения платформ

Это не баги, а особенности операционных систем:

- **Linux / Wayland** — Wayland не позволяет обычному приложению менять
  раскладку. Klatz-Klatz обнаружит такую сессию и честно предупредит вместо
  того чтобы молча не работать. Поддерживается только X11 (Xorg).
- **macOS** — системе может потребоваться разрешение на доступ к клавиатуре.
  Если раскладка не переключается, проверьте «Системные настройки → Конфиденциальность
  и безопасность → Доступность».
- **Windows** — приложение может переключить раскладку только в активном окне,
  поэтому при смене раскладки должно быть окно, в котором вы работаете.

## Сборка из исходников

Требуется [Rust](https://rustup.rs/) (stable) и [Node.js](https://nodejs.org/) 20+.

```bash
npm install
npm run tauri dev      # запуск с горячей перезагрузкой
npm run tauri build    # релизная сборка + установщик
```

Зависимости системы для Linux:

```bash
sudo apt install libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev patchelf
```

## Как это работает

Смена раскладки на каждой ОС устроена принципиально по-разному, поэтому весь
системный код изолирован в `src-tauri/src/platform/`, а остальное приложение
работает с общей моделью данных.

| Платформа | Механизм |
| --- | --- |
| Windows | `GetKeyboardLayoutList` для перечисления, `PostMessageW` с `WM_INPUTLANGCHANGEREQUEST` в активное окно |
| Linux | Разбор `setxkbmap -query`, переупорядочивание группы раскладок и повторный вызов `setxkbmap` |
| macOS | `TISCreateInputSourceList` / `TISSelectInputSource` из Carbon HIToolbox |

Идентификатор раскладки на Windows — это сам `HKL` в шестнадцатеричном виде
(например `04090419`), потому что у раскладок бывает одинаковая локаль при
разных раскладках клавиатуры (например US и Dvorak).

## Структура проекта

```
src/                      окно настроек (TypeScript, без фреймворков)
src-tauri/
  src/lib.rs              трей, горячая клавиша, команды для UI
  src/config.rs           настройки и их атомарное сохранение
  src/layouts.rs          модель раскладок и логика цикла (покрыта тестами)
  src/platform/           windows.rs / linux.rs / macos.rs
```

## Настройки

Хранятся в `%APPDATA%\com.klatz.klatz\config.json` (Windows),
`~/.config/com.klatz.klatz/config.json` (Linux),
`~/Library/Application Support/com.klatz.klatz/config.json` (macOS).

```json
{
  "layouts": ["04090419", "04190419"],
  "hotkey": "CmdOrCtrl+Shift+Space",
  "switchOnClick": true,
  "autostart": false
}
```
