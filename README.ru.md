# Klatz-Klatz — переключатель раскладки клавиатуры

[English](README.md) | [Русский](README.ru.md)

Кроссплатформенное приложение для трея, которое переключает раскладку клавиатуры по глобальной
горячей клавише или по клику на иконку. Написано на Rust + Tauri 2, устанавливается одним файлом,
работает на **Windows**, **Linux (X11)** и **macOS**.

Делает одну вещь и делает её локально: без аккаунта, без телеметрии, без обращений в сеть, без
автообновлений. Настройки — один JSON-файл рядом с другими конфигами приложений.

## Возможности

- **Глобальная горячая клавиша** — переключение по `Ctrl+Shift+Space` (настраивается, принимается
  любая комбинация).
- **Иконка в трее** — клик переключает раскладку, правая кнопка открывает меню.
- **Меню трея** — список установленных раскладок, активная отмечена галочкой.
- **Свой порядок в цикле** — раскладки перетаскиваются в окне настроек, и горячая клавиша обходит
  цикл именно в этом порядке.
- **Переключение по клику можно отключить** — оставить только горячую клавишу.
- **Автозапуск** — старт вместе с системой, переключается в окне настроек.
- **Окно настроек прячется в трей** — закрытие окна не завершает приложение.
- **Занятая горячая клавиша не ломает запуск** — если `Ctrl+Shift+Space` уже занята другой
  программой, Klatz-Klatz продолжает работать и показывает проблему в интерфейсе, а не отказывается
  стартовать.
- **Без фоновых служб** — ни сервисов, ни демонов, ни прав администратора.

## Установка

Скачайте сборку для вашей платформы со страницы [Releases](https://github.com/PrEvAl85/Klatz-Klatz/releases):

| Платформа | Файл |
|-----------|------|
| Windows | `Klatz-Klatz_0.1.0_x64-setup.exe` (NSIS) или `Klatz-Klatz_0.1.0_x64_en-US.msi` |
| macOS (Apple Silicon) | `Klatz-Klatz_0.1.0_aarch64.dmg` |
| macOS (Intel) | `Klatz-Klatz_0.1.0_x64.dmg` |
| Linux | `Klatz-Klatz_0.1.0_amd64.AppImage`, `Klatz-Klatz_0.1.0_amd64.deb` |

> **Windows SmartScreen (неподписанный exe).** Сборки Windows не подписаны цифровым сертификатом
> (подпись платная), поэтому Windows при первом запуске может показать «Windows защитил ваш
> компьютер». Это нормально — файл безопасен:
>
> - нажмите **«Подробнее» → «Выполнить в любом случае»** (одноразово);
> - или снимите пометку «скачано из интернета»: ПКМ по файлу → **Свойства** → галочка
>   **«Разблокировать»** → ОК;
> - либо из PowerShell: `Unblock-File Klatz-Klatz_0.1.0_x64-setup.exe`.

> **macOS.** При первом запуске системе может потребоваться разрешение на доступ к клавиатуре. Если
> раскладка не переключается, проверьте **Системные настройки → Конфиденциальность и
> безопасность → Доступность**.

## Ограничения платформ

Это не баги, а правила операционных систем:

- **Linux / Wayland** — Wayland не позволяет обычному приложению менять раскладку. Klatz-Klatz
  обнаруживает такую сессию и честно предупреждает вместо того чтобы молча не работать. Поддерживается
  только X11 (Xorg).
- **macOS** — системе может потребоваться разрешение в разделе «Доступность», см. выше.
- **Windows** — раскладку можно переключить только в активном окне, поэтому в момент переключения
  должно быть окно, в котором вы работаете.

## Как это работает

Смена раскладки на каждой ОС устроена принципиально по-разному, поэтому весь системный код изолирован
в `src-tauri/src/platform/`, а остальное приложение работает с общей моделью данных.

| Платформа | Механизм |
| --- | --- |
| Windows | `GetKeyboardLayoutList` для перечисления, `PostMessageW` с `WM_INPUTLANGCHANGEREQUEST` в активное окно |
| Linux | Разбор `setxkbmap -query`, переупорядочивание групп раскладок и повторный вызов `setxkbmap` |
| macOS | `TISCreateInputSourceList` / `TISSelectInputSource` из Carbon HIToolbox |

На Windows раскладка идентифицируется своим `HKL` в шестнадцатеричном виде (например `04090419`),
потому что у разных раскладок бывает одинаковая локаль — например US и Dvorak.

## Сборка и запуск

Требования: [Rust](https://rustup.rs) (stable), [Node.js](https://nodejs.org) ≥ 20, системные
зависимости [Tauri](https://tauri.app/start/prerequisites/).

```sh
npm install
npm run tauri dev     # разработка
npm run tauri build   # релизная сборка (msi/nsis/dmg/appimage/…)
```

Системные зависимости на Debian/Ubuntu:

```sh
sudo apt install libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev patchelf
```

## Проверки качества

```sh
cd src-tauri
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
```

Покрытие тестами: цикл раскладок (переход вперёд, переход через конец, единственная раскладка,
неизвестный текущий идентификатор, пустой цикл), перенос раскладки в начало цикла и работа с
конфигом (отсутствующие поля берут значения по умолчанию, устаревшие идентификаторы отбрасываются с
сохранением порядка, повреждённый файл откатывается к настройкам по умолчанию).

Те же проверки запускаются при каждом пуше в `main` и в каждом pull request (GitHub Actions).

## Настройки

Хранятся рядом с другими конфигами приложений:

- Windows — `%APPDATA%\com.klatz.klatz\config.json`
- Linux — `~/.config/com.klatz.klatz/config.json`
- macOS — `~/Library/Application Support/com.klatz.klatz/config.json`

```json
{
  "layouts": ["04090419", "04190419"],
  "hotkey": "CmdOrCtrl+Shift+Space",
  "switchOnClick": true,
  "autostart": false
}
```

`layouts` — это порядок цикла ровно в том виде, в котором вы его собрали в окне, а не копия
системного списка, поэтому свой порядок переживает перезапуск.

## Технические детали

- **Стек:** Tauri 2 (Rust) + веб-интерфейс (TypeScript, Vite, без UI-фреймворков).
- **Плагины:** `tauri-plugin-global-shortcut` (горячая клавиша),
  `tauri-plugin-autostart` (автозапуск).
- **Хранилище:** локальный JSON, пишется атомарно; данные не покидают компьютер.
- **Безопасность:** строгий CSP, никакого удалённого содержимого, единственный вызов внешней
  программы — `setxkbmap` на Linux X11.

## Структура проекта

```
src/                      окно настроек (TypeScript, без фреймворков)
src-tauri/
  src/lib.rs              трей, горячая клавиша, команды для UI
  src/config.rs           настройки и их атомарное сохранение
  src/layouts.rs          модель раскладок и логика цикла (покрыта тестами)
  src/platform/           windows.rs / linux.rs / macos.rs
```
